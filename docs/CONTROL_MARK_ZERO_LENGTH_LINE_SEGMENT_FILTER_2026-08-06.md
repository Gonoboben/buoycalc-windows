# Контрольная отметка: фильтрация нулевых расчётных сегментов линии

Дата: 2026-08-06

## Контекст

`BuoyCalculator.BuildSegmentRows(...)` разбивает каждый включённый участок линии на сегменты длиной не более 1 м.

Текущая последовательность вычислений:

```text
itemLength = max(0, inputLength)
segmentCount = max(1, ceil(itemLength / 1 м))
```

Поэтому участок с нулевой или отрицательной введённой длиной нормализуется до нуля, но всё равно создаёт один `SegmentCalculationRow`.

## Обнаруженная несогласованность

Нулевая строка имеет:

```text
StartLengthM = EndLengthM
SegmentLengthM = 0
ProjectedAreaM2 = 0
CurrentForceN = 0
WeightWaterKg = 0
```

Она не является физическим сегментом и не влияет на суммы, однако проходит через последующие read-model пути:

- увеличивает количество расчётных сегментов;
- появляется в таблицах сегментов и натяжений;
- создаёт дополнительный узел формы с повторяющимися координатами;
- передаётся в альтернативную и итерационную кандидатную форму.

## Требуемая граница

Для участка линии с нормализованной длиной `<= 0`:

1. Не создавать `SegmentCalculationRow`.
2. Добавить `0` в параллельный список `LineCurrentForces`.
3. Перейти к следующему участку линии.

Нулевая запись в `LineCurrentForces` обязательна для сохранения позиционного соответствия между участками линии и их строками `ElementCalculationRow`.

## Сохраняемое поведение

Без изменений остаются:

- строка самого участка в `ElementRows`;
- порядок участков линии;
- его длина, вес и сила, равные нулю;
- все положительные участки и их сегментация;
- суммарная длина, вес и сила линии;
- профиль течения, плотность, площадь, Cd и формула сопротивления;
- натяжения и формы для положительных сегментов;
- buoy, connector, payload и anchor calculations;
- solver, gate, stores, selected shape, 2D и PDF;
- публичные records, JSON/DTO, XAML, команды, версия и 3D-поведение.

## Допустимое изменение результата

Изменяется только топология read model для нулевых участков:

- уменьшается число сегментных строк;
- исчезают фиктивные строки натяжений и повторяющиеся узлы формы;
- числовые суммы сил, веса и длины остаются прежними.
