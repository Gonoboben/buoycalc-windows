# Контрольная отметка: терминология сравнений моделей в отчёте

Дата: 2026-08-05
Issue: #172

## Причина

Технический отчёт использует исторические подписи `старая`, `shape`, `Top T старая` и `Угол старый`. Они не объясняют, какие расчётные модели сравниваются.

## Зафиксированные названия

### Базовая сегментная модель

Источник значений `Original*`:

- `SegmentCalculationRow.CurrentForceN`;
- `SegmentTensionRow.TensionKn`;
- `SegmentTensionRow.AngleFromVerticalDeg`.

Модель суммирует силы сегментов и вес линии снизу вверх. Она не применяет поправку по X/Z-ориентации сегмента и не добавляет локальные нагрузки соединителей и приборов по координате `s`.

Пользовательское название: **базовая сегментная модель**.

### Модель по форме X/Z

Источник значений `Shape*`:

- нормальная составляющая скорости течения относительно X/Z-ориентации сегмента;
- накопленные натяжения, пересчитанные по этим силам.

Пользовательское название: **модель по форме X/Z**.

### Модель с дискретными нагрузками по s

Источник значений `Discrete*`:

- базовые распределённые нагрузки линии;
- локальный вес в воде и горизонтальная сила соединителей и приборов ниже рассматриваемого сечения по координате `s`.

Пользовательское название: **модель с дискретными нагрузками по s**.

## Разрешённые изменения

Только текстовые подписи в Markdown-renderers:

- итоговые строки;
- заголовки сравнительных разделов;
- поясняющие строки;
- заголовки столбцов;
- текстовые статусы, формируемые renderer-ом.

## Запрещённые изменения

- поля `Original*`, `Shape*`, `Discrete*`;
- формулы сил, натяжений и углов;
- порядок и состав строк;
- единицы и формат `0.####`;
- analyzer-ы и их `MethodNote`;
- solver, gate, stores, selected shape;
- 2D и PDF diagram source;
- JSON, DTO, XAML и версия приложения;
- 3D.

## Последовательность

1. Итоговые строки `TechnicalReportMarkdownBuilder`.
2. Подробные shape force/tension sections.
3. Подробные discrete tension/shape sections.

Каждый production PR должен проходить `.NET Build`, `Selected Shape Consumer Scan` и `Report Store Consumer Scan` до merge.
