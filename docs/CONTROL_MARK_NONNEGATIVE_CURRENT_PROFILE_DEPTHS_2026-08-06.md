# Контрольная отметка: неотрицательные глубины профиля течения

Дата: 2026-08-06  
Issue: #283

## Контекст

`CurrentProfilePointInput.DepthM` задаёт глубину точки ниже поверхности воды.

Окончательная input-граница удаляет неконечные значения, но не ограничивает знак конечной глубины. Отрицательная точка может попасть в сортировку и линейную интерполяцию `CurrentAtDepth(...)`, влияя на значения скорости и плотности около поверхности, хотя физически располагается выше поверхности.

Профиль может быть глубже текущей постановки и использоваться повторно для других проектов. Поэтому эта задача проверяет только нижнюю границу `DepthM >= 0` и не требует `DepthM <= environment.DepthM`.

## Цель

Добавить строку:

```text
CheckName: Неотрицательные глубины активного профиля течения
```

## Активность профиля

Если:

```text
UseCurrentProfile == false
```

отображается:

```text
Value: профиль отключён
Severity: OK
```

Если профиль включён, проверяются все элементы `EffectiveCurrentProfile`.

## Расчёт значений

```text
invalidDepthCount = count(!double.IsFinite(DepthM) || DepthM < 0)
minimumProfileDepthM = min(DepthM), либо NaN при пустом профиле
```

## Отображение

Пустой активный профиль:

```text
точек 0; отрицательных/неконечных глубин 0
```

Непустой активный профиль:

```text
min z=<minimumProfileDepthM> м; отрицательных/неконечных глубин <N>
```

Допуск:

```text
каждая DepthM >= 0 и конечна
```

## Severity

```text
OK    профиль отключён либо invalidDepthCount == 0
ERROR активный профиль содержит хотя бы одну отрицательную или неконечную глубину
```

## Проверяемые сценарии

### Профиль отключён

```text
Severity = OK
```

### Пустой профиль включён

```text
точек 0
Severity = OK
```

### Точки 0, 100 и 380 м

```text
min z=0 м
нарушений 0
Severity = OK
```

### Точка -5 м

```text
min z=-5 м
нарушений 1
Severity = ERROR
```

### Точка глубже проекта

```text
Project Depth = 380 м
Profile DepthM = 500 м
Severity = OK
```

Эта задача не ограничивает верхний диапазон профиля.

## Архитектурная граница

Production-изменение ограничивается:

```text
Services/EngineeringDiagnostics.cs
```

Допустимо изменить только инженерные diagnostic rows и общий diagnostic severity.

Не изменяются:

- коллекция профиля;
- порядок точек;
- сортировка и интерполяция;
- fallback плотности;
- `CalculationResult.Verdict`;
- `CalculationResult.MainRisk`;
- solver и координаты.

## Запрещённые изменения

В рамках Issue #283 запрещено:

- удалять, перемещать или исправлять точки;
- применять `Math.Abs` или clamping к глубине;
- запрещать точки глубже проектной глубины;
- менять U/V/W или плотность;
- менять drag, волну, вес, плавучесть, натяжение или якорь;
- менять solver, gate, stores или selected-shape routing;
- менять 2D/PDF координаты;
- менять JSON/DTO, XAML или команды;
- добавлять 3D.

## Порядок строки

Строка размещается рядом с существующей диагностикой уникальности глубин активного профиля.

## Условия merge

Сначала документационный PR, затем отдельный production PR.

Оба PR объединяются только после успешных проверок:

- `.NET Build`;
- `Selected Shape Consumer Scan`;
- `Report Store Consumer Scan`.
