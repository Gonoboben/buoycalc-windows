# Контрольная отметка: глубина выборки и локальная скорость сегментов

Дата: 2026-08-06  
Issue: #309  
Область: инженерная диагностика сегментного read model

## 1. Контекст

Каждый расчётный сегмент публикует:

```text
EstimatedDepthM
LocalSpeedMS
```

Глубина используется для выборки профиля течения и плотности, а локальная скорость — в расчёте распределённого сопротивления линии.

Действующая модель формирует глубину как значение внутри диапазона:

```text
0 .. max(0, projectDepth)
```

Локальная скорость является модулем горизонтального профиля либо активной скалярной скоростью. Поэтому она должна быть конечной и неотрицательной.

## 2. Диагностика глубины выборки

Название:

```text
Глубина выборки расчётных сегментов
```

Нарушение:

```text
EstimatedDepthM неконечна
или EstimatedDepthM < 0
или EstimatedDepthM > max(0, Depth) + 1e-9 м
```

Отображение для непустой коллекции:

```text
min z=<минимум> м; max z=<максимум> м; нарушений <N>; сегментов <C>
```

Для пустой коллекции:

```text
сегментов нет; нарушений 0
```

Допуск:

```text
0 <= zseg <= max(0, Depth) (+1e-9 м)
```

Статус:

```text
OK    — нарушений 0
ERROR — нарушений больше 0
```

## 3. Диагностика локальной скорости

Название:

```text
Неотрицательная локальная скорость сегментов
```

Нарушение:

```text
LocalSpeedMS неконечна или < 0
```

Отображение для непустой коллекции:

```text
min Ulocal=<минимум> м/с; max Ulocal=<максимум> м/с; нарушений <N>; сегментов <C>
```

Для пустой коллекции:

```text
сегментов нет; нарушений 0
```

Допуск:

```text
каждая Ulocal >= 0 и конечна
```

Статус:

```text
OK    — нарушений 0
ERROR — нарушений больше 0
```

## 4. Разделение ответственности

Новые строки проверяют уже рассчитанный сегментный read model.

Они не заменяют:

- проверку положительной проектной глубины;
- проверки scalar/profile течения;
- проверку глубин опорных точек профиля;
- проверки плотности, площади и Cd;
- проверки сегментных сил и их агрегации.

Пустая коллекция проходит эти локальные инварианты; наличие активной линии и сегментов контролируется другими строками.

## 5. Сохранение поведения

Не изменять:

- расчёт `EstimatedDepthM`;
- выбор `LocalSpeedMS`;
- профильную интерполяцию и плотность;
- формулу drag и силы;
- сегментацию 0,20 м и отсутствие лимита числа сегментов;
- веса, натяжения, слабое звено и резервы;
- якорную модель;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды и версию;
- 3D-область.
