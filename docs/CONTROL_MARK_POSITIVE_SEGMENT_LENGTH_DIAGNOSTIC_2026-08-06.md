# Контрольная отметка: диагностика положительной длины расчётных сегментов

Дата: 2026-08-06

## Контекст

После Issue #246 расчётное ядро не создаёт `SegmentCalculationRow` для участка линии с нулевой нормализованной длиной.

Инженерная диагностика уже сравнивает:

- общую длину линии и сумму длин сегментов;
- вес участков линии и сумму весов сегментов;
- силу участков линии и сумму сил сегментов.

## Недостаточность существующих сумм

Суммарная проверка длины не гарантирует положительность каждого отдельного сегмента.

Например, набор длин:

```text
0 м + 10 м
```

может сохранить общий итог `10 м`, хотя первая строка не является физическим сегментом.

Поэтому требуется независимый инвариант на уровне строк.

## Новая диагностическая строка

Название:

```text
Положительная длина расчётных сегментов
```

Расчёт:

```text
nonPositiveCount = количество SegmentRows, где SegmentLengthM <= 0
minimumLengthM = минимальная SegmentLengthM, если строки существуют
```

Допуск:

```text
каждый SegmentLengthM > 0
```

Severity:

```text
OK, если nonPositiveCount = 0
ERROR, если nonPositiveCount > 0
```

Пустая коллекция сегментов считается `OK` именно для этого локального инварианта. Отсутствие расчётной линии и формы контролируется другими существующими проверками.

## Сохраняемое поведение

Без изменений остаются:

- создание и нумерация сегментов;
- длины, веса, силы, плотность, площадь и Cd;
- натяжения, углы и форма;
- расчётный verdict и main risk;
- buoy, connector, payload и anchor calculations;
- solver, gate, stores, selected shape, 2D и PDF;
- публичные records, JSON/DTO, XAML, команды, версия и 3D-поведение.

Новая строка влияет только на `EngineeringDiagnosticsResult.OverallSeverity`, если в read model появится неположительный сегмент.

## Предпочтительная реализация

Отдельный production PR:

- изменить только `Services/EngineeringDiagnostics.cs`;
- вычислить количество неположительных строк и минимальную длину рядом с существующей проверкой суммарной длины;
- добавить одну `EngineeringDiagnosticRow` после проверки согласованности длины;
- не менять существующие строки и их порядок относительно друг друга.
