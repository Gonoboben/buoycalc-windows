# Контрольная отметка: положительные коэффициенты удержания якоря

Дата: 2026-08-06  
Issue: #293  
Область: инженерная диагностика якорной модели

## 1. Контекст

Расчётный результат публикует три множителя модели удержания:

```text
AnchorBaseHoldingCoefficient
AnchorTypeMultiplier
SeabedHoldingMultiplier
```

Действующая формула:

```text
AnchorHoldingKg = AnchorWeightWaterKg
    × AnchorBaseHoldingCoefficient
    × AnchorTypeMultiplier
    × SeabedHoldingMultiplier
```

Каждый множитель должен быть конечным и строго положительным. Нулевое, отрицательное или неконечное значение делает физический смысл итогового удержания недопустимым.

Существующий контроль запаса якоря показывает производный итог, но не определяет, какой именно множитель нарушен.

## 2. Диагностическая строка

Название:

```text
Положительные коэффициенты удержания якоря
```

Значение:

```text
Kякоря=<AnchorBaseHoldingCoefficient>;
Kтипа=<AnchorTypeMultiplier>;
Kгрунта=<SeabedHoldingMultiplier>;
нарушений <N>
```

Нарушением считается каждый коэффициент, для которого:

```text
не конечен или <= 0
```

Допуск:

```text
каждый K > 0 и конечен
```

Статус:

```text
OK    — нарушений 0
ERROR — нарушений больше 0
```

## 3. Разделение ответственности

Новая строка проверяет только множители модели удержания.

Она не заменяет существующие проверки:

- положительного веса якоря в воде;
- итогового запаса удержания якоря;
- заданности грунта;
- специальных примечаний для грузового якоря на каменистом грунте.

## 4. Сохранение поведения

Не изменять:

- введённые коэффициенты;
- выбор типа якоря и функцию `AnchorTypeMultiplier`;
- грунтовый каталог и выбор множителя грунта;
- формулы веса якоря в воде, удержания и запаса;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- силы, слабое звено и натяжения;
- сегментацию 0,20 м и отсутствие лимита числа сегментов;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды и версию;
- 3D-область.
