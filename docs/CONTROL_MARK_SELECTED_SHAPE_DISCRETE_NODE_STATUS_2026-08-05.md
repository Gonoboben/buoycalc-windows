# Контрольная отметка: статус дискретного узла в выбранной X/Z-форме

Дата: 2026-08-05
Issue: #196
Scope: documentation only

## Причина

В разделе технического отчёта `Область учёта элементов в текущей модели` для соединителей и приборов в колонке `Основная форма X/Z` сейчас выводится:

```text
нет, дискретный узел пока не вставлен
```

Слово `пока` описывает это как незавершённую будущую работу. Текущая архитектура фактически использует две разные формы представления.

## Выбранная форма

`MooringDiscreteLoadShapeBuilder` строит кандидатную геометрию по строкам сегментных натяжений с дискретными нагрузками.

`MooringIterativeSolver.ToShapeResult(...)` преобразует строки этой геометрии в `MooringShapePoint` и создаёт `MooringShapeResult`.

Узлы выбранного `MooringShapeResult` соответствуют геометрии линии и границам сегментов. Отдельные точки соединителей и приборов в этот список не добавляются.

При этом их локальные нагрузки по координате `s` участвуют в натяжениях с дискретными нагрузками и могут влиять на кандидатную, а после gate — и на выбранную геометрию.

## Отдельные дискретные X/Z-точки

`MooringAlternativeDiscreteNodeProjector` независимо интерполирует X/Z-положение каждого дискретного элемента по его координате `s`.

Эти точки:

```text
- хранятся в MooringAlternativeDiscreteNodeResult;
- передаются вместе с альтернативной формой в MooringAlternativeShapeStore;
- доступны 2D как отдельный сравнительный/визуальный read model;
- не заменяют и не расширяют список MooringShapeResult.Nodes.
```

## Точная production-правка

В `Services/TechnicalReportMarkdownMovedSections.cs` заменить только значение `shapeScope` для прочих элементов:

```diff
- нет, дискретный узел пока не вставлен
+ нет отдельного узла; влияние через нагрузку по s
```

Новая строка одновременно сообщает два действующих факта:

```text
- отдельной точки элемента в выбранном MooringShapeResult нет;
- нагрузка элемента учитывается через координату s и может влиять на геометрию.
```

## Инварианты

```text
- MooringShapeResult и MooringShapePoint не меняются;
- MooringAlternativeDiscreteNodeResult не меняется;
- MooringAlternativeShapeStore и SelectedShapeStore не меняются;
- дискретные натяжения и кандидатная геометрия не меняются;
- gate, выбор формы и stores не меняются;
- 2D и порядок источников PDF не меняются;
- строки и столбцы таблицы не добавляются и не удаляются;
- JSON, DTO, XAML, команды и версия приложения не меняются;
- 3D не добавляется.
```

## Safety gate

Production PR с однострочной правкой сливается только после зелёных:

```text
.NET Build
Selected Shape Consumer Scan
Report Store Consumer Scan
```
