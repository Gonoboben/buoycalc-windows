# Контрольная отметка: модули скорости в сводке точки профиля

Дата: 2026-08-06

## Контекст

`CurrentProfilePointInput` содержит два разных модуля скорости:

```text
HorizontalSpeedMS = sqrt(U^2 + V^2)
SpeedMS = sqrt(U^2 + V^2 + W^2)
```

Текущая модель сопротивления линии использует горизонтальный модуль. Вертикальная компонента W сохраняется и интерполируется, но в drag не входит.

## Обнаруженная неоднозначность

`CurrentProfilePointViewModel.Summary` показывает только:

```text
|U| = SpeedMS
```

Это фактически 3D-модуль, но подпись не указывает этого и не показывает горизонтальный модуль, используемый расчётом сопротивления.

Окно профиля и технический отчёт уже различают эти величины, поэтому строка сводки остаётся последним неоднозначным пользовательским представлением.

## Требуемое представление

В сводке каждой точки показать оба существующих значения:

```text
|Uгор| = HorizontalSpeedMS
|U3D| = SpeedMS
```

## Сохраняемое поведение

Без изменений остаются:

- парсинг U, V, W, глубины и плотности;
- `ToInput()`, `ToDto()` и `FromDto()`;
- профиль, сортировка, интерполяция и резервная плотность;
- EffectiveCurrentSpeedMS и локальная скорость сегмента;
- все силы, веса, натяжения, формы и якорный расчёт;
- report, PDF, 2D, solver, gate, stores, selected shape;
- XAML, команды, версия и 3D-поведение.
