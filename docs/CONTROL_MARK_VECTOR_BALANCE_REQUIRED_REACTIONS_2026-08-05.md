# Контрольная отметка: требуемые реакции векторного баланса

Дата: 2026-08-05
Issue: #199
Scope: documentation only

## Причина

Раздел технического отчёта `Векторная ведомость сил постановки` сейчас использует исторические формулировки:

```text
Вычислена как минус сумма учтённых сил; пока не найдена solver-ом.
Статус баланса: каркас собран; реакции не решены
```

Они создают впечатление, что текущий этап является незавершённым solver-каркасом. Фактическая модель имеет другую, устойчивую границу.

## Текущая математика

`MooringVectorBalance.Build(...)` собирает строки сил и вычисляет:

```text
SumExternalFxN = Σ Fx учтённых строк
SumExternalFzN = Σ Fz учтённых строк
RequiredReactionFxN = -SumExternalFxN
RequiredReactionFzN = -SumExternalFzN
```

Горизонтальная удерживающая способность и запас якоря определяются отдельно:

```text
AnchorHorizontalCapacityN = max(0, AnchorHoldingKg) × g
AnchorHorizontalReserve = AnchorHorizontalCapacityN / |RequiredReactionFxN|
```

Эти формулы и значения в данном шаге не меняются.

## Семантика R

`RequiredReactionFxN` и `RequiredReactionFzN` являются алгебраически требуемыми реакциями для замыкания:

```text
ΣF + R = 0
```

Они не являются:

```text
- реакциями, найденными отдельным solver опор;
- результатом итерационного solver формы;
- доказательством полного решения равновесной системы;
- значениями, полученными из 2D или PDF.
```

`MooringVectorBalanceResult.IsSolved` сейчас всегда возвращается как `false`. Его поведение и тип результата не меняются.

## Точные production-правки

### Вводная строка раздела

```text
Таблица собирает силовые члены расчётного ядра. Значения R являются требуемыми реакциями для замыкания ΣF=0; отдельная система опорных реакций или равновесной формы здесь не решается.
```

### Примечание строки R

```text
Вычислена как минус сумма учтённых сил; это требуемое значение, а не решённая реакция опоры.
```

### Статус при IsSolved=false

```text
ведомость сформирована; показаны требуемые реакции
```

### MethodNote

```text
Силовые члены собраны в единую векторную ведомость; требуемые реакции вычислены как R = -ΣF. Это проверочная ведомость, а не решение опорных реакций или равновесной формы.
```
