# Контрольная отметка: столбец состояния учёта последовательности

Дата: 2026-08-05
Issue: #190
Scope: documentation only

## Причина

Раздел технического отчёта `Позиционная модель последовательности по s` выводит последний столбец с заголовком `Следующий шаг`.

Текущие значения этого столбца уже не описывают будущую разработку. Они фиксируют действующее участие элемента в расчётной модели:

```text
Линия  — участвует как распределённая линия.
Буй    — участвует как верхнее граничное условие плавучести.
Якорь  — участвует как нижнее граничное условие удержания.
Прочие — локальные вес в воде и сила учитываются ниже координаты s.
```

Поэтому пользовательский заголовок должен описывать текущее состояние учёта.

## Разрешённая production-правка

В `Services/TechnicalReportMarkdownMovedSections.cs` заменить только Markdown-заголовок:

```diff
- Следующий шаг
+ Состояние учёта
```

## Сохраняемая внутренняя граница

Свойство `MooringSequencePositionRow.NextStepNote` в этом шаге не переименовывается.

Причины:

- пользователь видит заголовок и значения, а не имя свойства;
- переименование record-свойства создаст лишний model/DTO churn;
- текущая задача не требует изменения контракта данных;
- значение свойства уже корректно описывает фактическое участие элемента.

## Инварианты

```text
- значения строк не меняются;
- порядок и количество строк не меняются;
- столбцы, кроме одного заголовка, не меняются;
- единицы и формат 0.#### не меняются;
- Escape(...) и Markdown-разметка строк не меняются;
- MooringSequencePositionRow и NextStepNote не переименовываются;
- расчёты, solver, stores и selected shape не меняются;
- 2D и источник PDF-схемы не меняются;
- JSON, DTO, XAML, команды и версия приложения не меняются;
- 3D не добавляется.
```

## Safety gate

Production PR с однострочной правкой сливается только после зелёных:

```text
.NET Build
Selected Shape Consumer Scan
Report Store Consumer Scan
```
