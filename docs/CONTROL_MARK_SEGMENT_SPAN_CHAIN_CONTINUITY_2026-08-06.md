# Контрольная отметка: интервалы и непрерывность цепочки сегментов

Дата: 2026-08-06  
Issue: #312  
Область: инженерная диагностика сегментации линии

## 1. Контекст

Существующая диагностика проверяет положительность и максимальную длину сегментов, а также равенство суммы длин общей длине линии.

Этого недостаточно для доказательства непрерывности: разрывы и перекрытия могут взаимно компенсироваться при той же суммарной длине.

Каждый сегмент публикует:

```text
Number
StartLengthM
EndLengthM
SegmentLengthM
```

## 2. Согласованность отдельного интервала

Диагностическая строка:

```text
Согласованность интервалов расчётных сегментов
```

Для каждого сегмента требуется:

```text
StartLengthM, EndLengthM и SegmentLengthM конечны
StartLengthM >= 0
EndLengthM > StartLengthM
abs((EndLengthM - StartLengthM) - SegmentLengthM) <= 1e-9 м
```

Отображение:

```text
max Δspan=<максимальная невязка> м; нарушений <N>; сегментов <C>
```

Для пустой коллекции:

```text
сегментов нет; нарушений 0
```

Статус `ERROR` возникает только при наличии нарушений.

## 3. Непрерывность цепочки

Диагностическая строка:

```text
Непрерывность цепочки расчётных сегментов
```

Строки анализируются в порядке `Number`, без изменения исходной коллекции.

Проверяется:

```text
первая Number = 1
каждая следующая Number = предыдущая Number + 1
abs(first.StartLengthM) <= 1e-9 м
abs(current.StartLengthM - previous.EndLengthM) <= 1e-9 м
abs(last.EndLengthM - CalculationResult.LineLengthM) <= 1e-9 м
```

Отображение:

```text
Δstart=<невязка начала> м;
max gap=<максимальный разрыв/перекрытие> м;
Δend=<невязка конца> м;
нарушений нумерации <N>;
сегментов <C>
```

Пустая коллекция проходит локальный инвариант; наличие линии и сегментов контролируется отдельными строками.

## 4. Сохранение поведения

Не изменять:

- порядок или содержимое `SegmentRows`;
- значения Start/End/Length и их округление;
- шаг 0,20 м и отсутствие лимита числа сегментов;
- общую длину линии;
- профиль, drag, силы, веса и натяжения;
- слабое звено, резервы и якорную модель;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды, версию и 3D-область.
