# Контрольная отметка: резервная плотность при интерполяции профиля течения

Дата: 2026-08-06

## Контекст

`CurrentProfilePointViewModel.Parse(...)` возвращает `0`, если поле плотности пустое или не распознано. Пользователь также может явно задать неположительную плотность.

Расчётное ядро уже определяет семантику такого значения как отсутствие локальной плотности:

```text
WaterDensityKgM3 <= 0 -> использовать EnvironmentInput.EffectiveWaterDensityKgM3
```

Эта семантика применяется для точки, возвращённой `CurrentAtDepth(...)`, после интерполяции.

## Обнаруженная несогласованность

`CurrentAtDepth(...)` интерполирует исходные значения плотности соседних точек:

```text
rho(z) = Lerp(upper.WaterDensityKgM3, lower.WaterDensityKgM3, t)
```

Если одна точка содержит `0`, а другая положительную плотность, промежуточное значение становится положительным и поэтому уже не проходит через резервную ветку.

Пример:

```text
верхняя точка: rho = 0
нижняя точка: rho = 1025 кг/м3
t = 0.5
текущее rho = 512.5 кг/м3
```

Такое значение не является ни введённой плотностью, ни резервной плотностью среды.

## Требуемая граница

Перед интерполяцией нормализовать плотность каждой опорной точки:

```text
normalizedRho = point.WaterDensityKgM3 > 0
    ? point.WaterDensityKgM3
    : environment.EffectiveWaterDensityKgM3
```

Затем интерполировать только нормализованные значения.

Для глубины выше первой или ниже последней точки возвращаемая плотность также должна быть нормализована по той же семантике.

## Сохраняемое поведение

Без изменений остаются:

- глубины и порядок точек профиля;
- интерполяция U, V и W;
- горизонтальная скорость `sqrt(U^2 + V^2)`;
- формула сопротивления `0.5 * rho * U^2 * A * Cd`;
- сегментация линии, площадь, Cd и вес сегмента;
- все значения при положительной плотности во всех точках;
- buoy, connector, payload, anchor, tension, shape, solver, gate, stores, selected shape, 2D и PDF;
- JSON/DTO, XAML, команды и версия приложения.

## Допустимое изменение результата

Числовой результат изменяется только для профилей, где хотя бы одна используемая опорная точка имеет неположительную плотность. В таких слоях локальная плотность теперь следует уже существующей резервной семантике вместо интерполяции невалидного нуля.
