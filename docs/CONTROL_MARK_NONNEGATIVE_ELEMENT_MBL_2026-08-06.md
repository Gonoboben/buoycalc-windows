# Контрольная отметка: неотрицательные MBL элементов

Дата: 2026-08-06  
Issue: #299  
Область: инженерная диагностика прочности элементов

## 1. Контекст

`ElementCalculationRow.BreakingLoadKn` хранит MBL, опубликованную для каждого элемента расчётной цепочки.

Действующее ядро выбирает слабое звено только среди строк:

```text
BreakingLoadKn > 0
```

и присваивает статус:

```text
BreakingLoadKn <= 0 => INFO: MBL не задан
```

Нулевая MBL используется как допустимое обозначение отсутствующих прочностных данных. Отрицательная либо неконечная MBL физически недопустима, но сейчас попадает в ту же ветвь, что и ноль, и исключается из выбора слабого звена без отдельного объяснения.

## 2. Диагностическая строка

Название:

```text
Неотрицательные MBL элементов
```

Проверяются все строки:

```text
CalculationResult.ElementRows
```

Нарушение:

```text
BreakingLoadKn неконечна или < 0
```

Ноль разрешён и сохраняет существующую семантику:

```text
0 = MBL не задана
```

Отображение для непустой коллекции:

```text
min MBL=<минимум> кН; отрицательных/неконечных <N>; нулевых <Z>
```

Для пустой коллекции:

```text
строк элементов нет; нарушений 0; нулевых 0
```

Допуск:

```text
каждая MBL >= 0 и конечна; 0 = не задана
```

Статус:

```text
OK    — нарушений 0
ERROR — нарушений больше 0
```

## 3. Разделение ответственности

Новая строка проверяет только знак и конечность опубликованных MBL.

Она не заменяет:

- существующую проверку наличия хотя бы одного элемента с положительной MBL;
- выбор слабого звена;
- контроль WLL и коэффициента запаса;
- контроль фактического резерва слабого звена.

Нулевые MBL не повышают локальную severity этой строки, но продолжают учитываться существующими проверками полноты прочностных данных.

## 4. Сохранение поведения

Не изменять:

- MBL элементов;
- статус строк при `MBL <= 0`;
- фильтр `BreakingLoadKn > 0` при выборе слабого звена;
- WLL, коэффициент запаса и reserve;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- силы, веса, плавучесть, течение и волну;
- якорную модель;
- сегментацию 0,20 м и отсутствие лимита числа сегментов;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды и версию;
- 3D-область.
