# Контрольная отметка: неотрицательные рассчитанные силы сопротивления

Дата: 2026-08-06  
Issue: #302  
Область: инженерная диагностика опубликованных сил drag

## 1. Контекст

Расчётный read model публикует силы сопротивления на трёх уровнях:

```text
ElementCalculationRow.CurrentForceN
SegmentCalculationRow.CurrentForceN
CalculationResult.CurrentForceN
CalculationResult.WaveForceN
CalculationResult.HorizontalForceN
```

При конечной положительной плотности и неотрицательных площади и `Cd` общая формула drag не может создавать отрицательную силу-модуль:

```text
F = 0.5 × rho × velocity² × A × Cd
```

Отрицательная либо неконечная опубликованная сила означает нарушение входных инвариантов, регрессию формулы или несогласованность агрегации.

## 2. Диагностическая строка

Название:

```text
Неотрицательные рассчитанные силы сопротивления
```

Проверяются:

- все `ElementRows.CurrentForceN`;
- все `SegmentRows.CurrentForceN`;
- итоговая сила течения `CurrentForceN`;
- волновая добавка `WaveForceN`;
- итоговая горизонтальная сила `HorizontalForceN`.

Нарушение:

```text
значение неконечно или < 0
```

Ноль разрешён для:

- отсутствующего течения или волны;
- нулевой площади либо `Cd`;
- якоря и других строк без drag;
- пустой локальной коллекции.

## 3. Отображение

Строка показывает:

```text
элементы: min F=<минимум или нет данных>; нарушений <E>;
сегменты: min F=<минимум или нет данных>; нарушений <S>;
агрегаты: Fтеч=<CurrentForceN>; Fволн=<WaveForceN>; Fгор=<HorizontalForceN>; нарушений <A>
```

Допуск:

```text
каждая F >= 0 и конечна
```

Статус:

```text
OK    — E + S + A = 0
ERROR — хотя бы одно нарушение
```

## 4. Разделение ответственности

Новая строка контролирует знак и конечность уже опубликованных сил.

Она не заменяет:

- проверку плотности;
- проверки площади и `Cd`;
- согласованность элементной и сегментной силы линии;
- векторную ведомость;
- контроль натяжений и формы.

## 5. Сохранение поведения

Не изменять:

- значения сил;
- формулу drag;
- scalar/profile течение и интерполяцию;
- волну и плотность;
- агрегацию сил;
- натяжения, слабое звено и резервы;
- якорную модель;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- сегментацию 0,20 м и отсутствие лимита числа сегментов;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды и версию;
- 3D-область.

## 6. Production scope

Допустимый production-файл:

```text
Services/EngineeringDiagnostics.cs
```

Отчёт меняется только через существующую таблицу инженерной диагностики.
