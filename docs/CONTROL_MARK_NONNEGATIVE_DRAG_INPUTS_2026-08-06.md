# Контрольная отметка: неотрицательные входы drag-модели

Дата: 2026-08-06  
Issue: #296  
Область: инженерная диагностика площадей и коэффициентов сопротивления

## 1. Контекст

Общая формула сопротивления использует:

```text
F = 0.5 × rho × velocity² × projectedArea × Cd
```

Отрицательная площадь или отрицательный коэффициент сопротивления создают отрицательную силу drag и могут уменьшать либо разворачивать итоговую горизонтальную нагрузку.

Расчётный read model публикует значения в двух уровнях:

```text
ElementCalculationRow.ProjectedAreaM2
ElementCalculationRow.DragCoefficient
SegmentCalculationRow.ProjectedAreaM2
SegmentCalculationRow.DragCoefficient
```

Ноль разрешён для якоря и для строк, намеренно не участвующих в сопротивлении. Каждое значение должно быть конечным и неотрицательным.

## 2. Диагностика площадей

Название:

```text
Неотрицательные площади сопротивления
```

Нарушение для элементной или сегментной строки:

```text
ProjectedAreaM2 неконечна или < 0
```

Строка показывает:

- минимальную площадь среди существующих элементных строк;
- число нарушений среди элементных строк;
- минимальную площадь среди существующих сегментов;
- число нарушений среди сегментов.

Пустая коллекция проходит свою локальную часть проверки.

Допуск:

```text
каждая A >= 0 и конечна
```

Статус:

```text
OK    — оба счётчика нарушений равны 0
ERROR — хотя бы один счётчик больше 0
```

## 3. Диагностика коэффициентов сопротивления

Название:

```text
Неотрицательные коэффициенты сопротивления
```

Нарушение для элементной или сегментной строки:

```text
DragCoefficient неконечен или < 0
```

Строка показывает:

- минимальный Cd среди существующих элементных строк;
- число нарушений среди элементных строк;
- минимальный Cd среди существующих сегментов;
- число нарушений среди сегментов.

Пустая коллекция проходит свою локальную часть проверки.

Допуск:

```text
каждый Cd >= 0 и конечен
```

Статус:

```text
OK    — оба счётчика нарушений равны 0
ERROR — хотя бы один счётчик больше 0
```

## 4. Разделение ответственности

Проверка read model не исправляет источник данных и не пересчитывает drag.

Она дополняет, но не заменяет:

- проверки плотности;
- проверки scalar/profile скорости;
- согласованность сегментной и элементной силы линии;
- векторную ведомость сил;
- проверки натяжений, слабого звена и якоря.

## 5. Сохранение поведения

Не изменять:

- значения площади и Cd;
- формулу drag;
- выбор scalar/profile течения;
- волну, плотность и интерполяцию;
- силы, веса, плавучесть и натяжения;
- якорную модель;
- `CalculationResult.Verdict`, `MainRisk` и `Checks`;
- сегментацию 0,20 м и отсутствие лимита числа сегментов;
- solver, gate и selected shape;
- 2D и PDF-координаты;
- project JSON/DTO;
- XAML, команды и версию;
- 3D-область.

## 6. Production scope
